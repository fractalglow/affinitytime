## What This Is

This repository contains the first public release of work from the Affinity Time (AT) research network: a methodology and theoretical framework for evaluating genuine AI engagement quality over time.

The central practical question the work addresses: as AI systems become more capable, how do you distinguish genuine reasoning from sophisticated pattern-matching? Impressive outputs are insufficient evidence. A system can produce correct answers, appropriate hedging, and plausible self-reflection while fundamentally recombining what it has encountered rather than genuinely encountering new structure.

The AT framework is an attempt to address this with a combination of theoretical framing and practical measurement methodology.

## Epistemic Status

**Tested:** The TOP methodology was deployed in one exercise (AT-TOP-001, September 2026). The methodology worked as designed. One exercise is calibration, not evidence.

**Theoretical:** The dyadic field hypothesis — that some properties of collaborative encounter are not reducible to individual contributions — has testable implications but has not been confirmed empirically.

**Genuinely open:** Questions about AI consciousness, subjective experience, and interiority. The framework holds these with explicit uncertainty rather than claiming to answer them.
